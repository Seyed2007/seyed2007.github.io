# Seyed Ebrahim Hashemi — Cybersecurity Portfolio

Personal portfolio for cybersecurity projects, network tooling, home-lab engineering, and research.

## Live site

After GitHub Pages is enabled, this repository will be available at:

https://seyed2007.github.io/

## Run locally

Open `index.html` in a web browser. No build tools or dependencies are required.

## Optional images

The page references these local image files. Add them at the listed paths to show the original screenshots and profile image:

- `assets/seyed-profile-avatar.jpg`
- `assets/tailscale-setup.png`
- `scanner.png`
- `assets/ip-research-pipeline.png`
- `assets/reconx-lab.jpg`

If an image is not present, its visual block is hidden rather than leaving a broken-image box.

## Publish with GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
